This page is a WIP. The goal is to reorganize code from a paper I authored titled "Spatial variation of asthma rates in Los Angeles County by environmental and socioeconomic indicators". 

This repository serves 2 purposes:

  1. To learn how to use the program
  2.  To make my own work reproducible and verifiable. 

This code requires shapefiles to run. Shapefiles will be uploaded as well. The shapefiles were initially altered/edited in GIS. Further spatial analyses were done in RStudio.

Datasets (provided) will also need to be downloaded. 

The paper this repository supplements can be found here: [DOI: 10.1186/s12940-026-01298-4 ](https://doi.org/10.1186/s12940-026-01298-4)
